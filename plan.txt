Saya ingin membangun sebuah high-performance server framework C++ modern yang memiliki developer experience terinspirasi dari framework seperti ElysiaJS/Fastify, tetapi dirancang dari awal untuk ekosistem C++.

Nama proyek sementara: elaina-cpp

Tujuan akhirnya adalah membuat framework yang memungkinkan developer membuat server dengan API yang sederhana seperti:

#include <framework/framework.hpp>

int main() {
    Server app;

    app.get("/", [](Context& ctx) {
        return ctx.text("Hello World");
    });

    app.get("/users/:id", [](Context& ctx) {
        return ctx.json(...);
    });

    app.listen(3000);
}

API di atas HANYA contoh awal. Jangan menganggap desain tersebut sudah benar. Kamu harus mengevaluasi dan memperbaikinya jika ada desain yang lebih idiomatis, aman, cepat, atau mudah dikembangkan dalam C++.
